## 二、重点修复的机制性错误（A 级精选）

| 主题 | 错误原稿表述 | 修复后的源码事实 |
|---|---|---|
| Distro 校验机制 | Checksum 对账、60s 全量同步兜底（full.sync.interval）、不一致触发全量拉取 | `(clientId, revision)` 摘要校验（默认 5s，`DistroVerifyTimedTask`），失败后责任节点 delay=0 单条补推；`DistroConstants` 仅 7 项配置，全量快照仅启动时装载一次 |
| Distro 责任路由 | TreeMap 一致性哈希环、虚拟节点 | 排序健康节点列表 + `hashCode % size` 取模（`DistroMapper`），UP+SUSPICIOUS 计入、DOWN 摘除 |
| 成员状态机 | `ISOLATION` 为运维主动隔离状态、`MemberHealthCheckTask` 心跳 | `ISOLATION` 为预留死枚举（全仓 0 写入点）；探活为 `MemberInfoReportTask`（5s 轮询）+ `UnhealthyMemberInfoReportTask`（5s 专探非 UP 成员），`fail-access-cnt` 默认 3 |
| JRaft 选举安全 | "JRaft 启用 Pre-Vote、3 层检查阻止双 Leader"（ch11） | 2.5.3 未开启 Pre-Vote（无 `setEnablePreVote` 调用，默认 false）；收敛由 Term 单调递增 + 退位机制保证 |
| 推送重试 | maxRetry=3、500ms 间隔、超限降级 Long Polling、优先级队列 | 失败无限重排（`pushTaskRetryDelay` 默认 1000ms），`NoRequiredRetryException` 为唯一放弃路径；优先级队列为 1.x 遗留 |
| gRPC 端口 | 集群端口 server.port+2000=10848、SDK/Cluster 共用端口 | SDK=+1000（9848）、Cluster=+1001（9849）、Raft=主端口-1000（7848，自动推导不可配置） |
| persistence 模块（ch06 重灾区） | `DynamicDataSource extends AbstractRoutingDataSource`、`@Bean` 工厂、`ModifyBuilder` DSL、`QueryType` 枚举、`DerbyImportEvent` 跨节点同步、DatasourceMetrics 全套指标 | 全部按源码重写：单例适配器、`ApplicationContextInitializer`+Condition 静态标志机制、纯 POJO SQL 请求模型（executeNo/sql/args）、byte 常量类、进程内 SlowEvent（仅 boolean finished）+ 跨节点快照走 JRaft、仅 `nacos_exception` 计数器 |
| 鉴权体系（ch07/ch08） | console 含用户/角色/权限 Controller、BCrypt 12 轮、Token 黑名单、`JwtTokenUtils`、IdentityContext 结构化字段 | 用户/角色/权限在 plugin-default-impl；BCrypt 默认 10 轮（SafeBcryptPasswordEncoder 72 字符限制）；无 Token 黑名单；`JwtTokenManager`/`NacosJwtParser`；IdentityContext 为通用键值 Map |
| 防雪崩 | `ProtectManager`、`nacos.core.protect.threshold`（CPU 阈值+多级降级）、`nacos.naming.protect.*` | 服务级元数据 `ServiceMetadata.protectThreshold`（默认 0.0）+ `ServiceUtil.selectInstancesWithHealthyProtection`，无 CPU 维度保护 |
| 客户端心跳 | `BeatReactor`/`NamingProxy.beat` 心跳任务 | 2.x 无客户端侧业务心跳；gRPC 长连接 + `NamingGrpcRedoService` 重做（redoDelayTime 默认 3000ms） |
| 日志体系 | `RaftCore - leader changed`、`remote-server.log`、`embedded-storage.log`、`nacos-config.log` 等虚构 logger/文件 | 真实日志：`[serverlist] changed to : ...`、`protocol-raft.log`、`remote-core/remote-digest/remote-push.log`、`~/logs/nacos/` 下 config.log/naming.log/remote.log |
| 集群部署（ch10） | cluster.conf 写 Raft 端口 7848、Learner 角色、12 张表 | cluster.conf 写主端口 8848（Raft 端口自动推导）；无 Learner 角色（Nginx 接入层实现读写分离）；13 张表（含 2.5.0 的 config_info_gray） |
